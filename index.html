Como alterar os agendamentos

  1. Abra o arquivo jobs.json no seu repositório GitHub.
  2. Edite ou adicione um item seguindo o exemplo abaixo.
  3. Salve com Commit changes. O GitHub Actions executará os itens habilitados nos intervalos configurados.
{
  "jobs": [
    {
      "name": "Meu site",
      "url": "https://exemplo.com/health",
      "method": "GET",
      "enabled": true,
      "interval_minutes": 5
    }
  ]
}

Esta versão executa no máximo uma requisição por destino em cada execução agendada, com intervalo mínimo de 5 minutos. A atualização do painel depende da publicação do status pelo GitHub Actions e do cache do GitHub Pages.
