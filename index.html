Como alterar os agendamentos

  1. Abra o arquivo jobs.json no seu repositório GitHub.
  2. Edite ou adicione um item seguindo o exemplo abaixo.
  3. Salve com Commit changes. O GitHub Actions executará os itens habilitados nos intervalos configurados.
{
  "jobs": [
    {
      "name": "Meu site",
      "url": "https://exemplo.com/health",
      "method": "GET",
      "enabled": true,
      "interval_minutes": 5
    }
  ]
}

Limite desta versão: uma requisição por destino em cada execução agendada; intervalo mínimo de 5 minutos. Não é uma ferramenta de teste de carga.

O histórico detalhado fica na aba Actions do repositório. O painel mostra o registro publicado pelo workflow.
