Como configurar

Edite jobs.json no GitHub e faça commit. Para iniciar imediatamente, abra Actions → HTTP Cron → Run workflow.

{
  "jobs": [{
    "name": "Meu site",
    "url": "https://seu-dominio.com/health",
    "method": "GET",
    "enabled": true,
    "duration_seconds": 60
  }]
}

Taxa fixa de até 1 requisição por segundo. Duração máxima de 240 segundos por execução. Apenas um destino ativo por vez. Use somente em sistemas que você controla ou tem autorização para testar.

O resultado resumido fica em status.json. O log completo fica na aba Actions.
